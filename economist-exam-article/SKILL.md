# Economist-Style Exam Article（经济学人风格 · 考研英语一阅读）

## 目的（Purpose）

输入：用户提供的约 100 个单词。输出：一份完整的考研英语一阅读练习包（docx 按「练习 → 解析 → 精读 → 默写」四部分组织）：

1. **Part 1 · 练习页**：纯英文原文（不加粗、无翻译，真题排版）+ 5 道阅读理解题（21-25）。
2. **Part 2 · 解析页**：答案速查 + 每题逐条解析（定位原文、为何对、干扰项如何错）。
3. **Part 3 · 精读页**：带注释英文原文（目标词**加粗**并紧跟斜体括号中文释义）+ 逐段中文翻译。
4. **Part 4 · 默写页**：全部词汇表（Word / 词性），**释义列留空**，供用户默写自测。

## 触发条件（When to use）

用户提供英文单词列表（通常约 100 个），并要求满足以下任一关键词时使用本技能：

- 经济学人风格 / Economist style / 仿经济学人写文章
- 考研英语一难度 / 考研阅读 / 阅读理解练习题
- 中英双语 / 中英对照 / bilingual article
- 输出 Word / docx 文件

## 工作流程（Workflow）

### Step 1 — 收集输入
确认或合理推断以下信息（仅在真正模糊时才提问）：
- **单词列表**：用户提供的全部单词（记录原始拼写，不得自行改动）。
- **板块（section）**：默认「商业 Business」，用户可指定 Leaders / Finance & economics /
  Science & technology / Culture / China / International 等。
- **主题（topic）**：未指定时，在该板块下选一个有争议性、可辩论的当代议题
  （如 AI 监管、供应链韧性、数据隐私、人口结构、气候政策等）。
- **题号**：默认 21-25（模拟 Text 1），用户另有要求除外。

### Step 2 — 撰写英文原文
严格遵循 `references/writing-guide.md` 中的风格与难度标准：

- 经济学人文风：开篇即观点、短句有力、长句表复杂关系、数据或具体细节支撑、
  克制的冷幽默、无明显说教。
- 考研英语一难度：篇幅 450-600 词（比标准真题略长，以容纳更多目标词）；
  每段至少 1-2 个含从句的长难句；目标词之外的词汇控制在考研大纲范围内。
- **尽量多用目标词（目标 ≥ 85/100）**：按语义自然分布到各段，同一词只用一次。
  无法自然嵌入的词不强塞，留在文末词汇表中即可（仍算全部 100 词覆盖）。
- 所有用到的目标词内联标记为 `**word**(*中文释义*)`，脚本会自动渲染为
  **加粗单词** + *斜体(中文翻译)*。注意：释义内部不要使用半角括号 `()` 或星号 `*`；
  如需补充注释请用全角括号「（）」。
- 给出英文标题：经济学人风格（短、有力、常含冒号或双关），并附中文副标题。

### Step 3 — 撰写中文翻译
逐段对照的忠实而通顺的译文；专有名词、机构名保留英文或加注。

### Step 4 — 出题（5 道）
按考研英语一 Part A 命题规范（详见 `references/writing-guide.md`）：

- 5 题覆盖不同题型：细节题、推断题、主旨大意题、词义猜测题、态度题/例证题。
- 每题 4 个选项（A-D），仅 1 个正确；干扰项须"像真的"——
  偷换概念、无中生有、以偏概全、过度推断、答非所问。
- 题干与选项用词须清晰、不诱导；正确项在原文有明确依据。

### Step 5 — 答案与解析
- 先给答案速查行：`21.B  22.D  23.A  24.C  25.B`。
- 每题解析：正确项原文定位 + 为什么对；再简要说明各干扰项错在哪。

### Step 6 — 生成 docx
1. 将全部内容按下方 JSON 格式写入工作区 `output/` 目录（文件名如
   `economist_practice_YYYYMMDD.json`）。
2. 执行打包脚本（替换 `<SKILL_DIR>` 为技能实际路径）：
   ```bash
   /Users/speirpicwung/.workbuddy/binaries/python/envs/default/bin/python \
     <SKILL_DIR>/scripts/build_docx.py <json路径> -o <输出.docx路径>
   ```
3. 检查 docx 已生成，向用户报告输出路径。

## JSON 输入格式（build_docx.py 的输入）

```json
{
  "title": "The Paper Chase: Why Banknotes Refuse to Die",
  "subtitle": "纸币的坚持：现金为何迟迟不退场",
  "section": "Business",
  "english_article": "第一段……\n\n第二段……（段落之间以空行分隔；目标词用 **word**(*翻译*) 标记）",
  "chinese_article": "第一段译文……\n\n第二段译文……",
  "questions": [
    {
      "number": 21,
      "stem": "According to the passage, ...",
      "options": ["A. ...", "B. ...", "C. ...", "D. ..."],
      "answer": "B",
      "explanation": "解析文本"
    }
  ],
  "vocabulary": [
    {"word": "ephemeral", "pos": "adj.", "translation": "短暂的，转瞬即逝的"}
  ]
}
```

字段说明：
- `questions` 固定 5 项，`number` 为 21-25，`answer` 为 A/B/C/D 之一。
- `vocabulary` 必须包含用户提供的全部单词（文章里用到的 + 没用到的），顺序可
  按词性或原文出现顺序排列；`pos` 为词性（n./v./adj./adv./prep./phrase 等）。

## docx 排版规范（脚本自动完成）

**字体**：全文档统一 Times New Roman（西文）+ 宋体（中文）；文章大标题用黑体；
已设置 Normal 默认样式，杜绝字体回退。正文 1.5 倍行距、段后 8pt、字符间距 0.2pt（标题 0.3pt），
整体排版疏朗舒适。

docx 按「练习 → 解析 → 精读 → 默写」四部分组织，各部分之间以**分页符**分隔：

**Part 1 · 练习区**（页首标题区后）
1. 页首：英文标题（居中加粗，黑体）+ 中文副标题 + 元信息行（板块、词数、词汇数）。
2. 【Part 1 · 英文原文】（纯阅读版）：**不加粗、不附翻译**的干净英文，**独立成页**，与真题排版一致。
3. 【Part 1 · 阅读理解题】：题干加粗，四个选项换行缩进排列（21-25）；**单独起新页**。

**Part 2 · 解析页**（新页开始）
4. 【Part 2 · 参考答案与解析】：答案速查一行 + 每题「【答案】X【解析】……」及干扰项辨析。

**Part 3 · 精读页**（新页开始）
5. 【Part 3 · 英文原文】（精读版）：目标词**加粗 + 斜体括号释义**，首行缩进、两端对齐、1.5 倍行距。
6. 【Part 3 · 中文翻译】：逐段对应译文。

**Part 4 · 默写页**（新页开始）
7. 【Part 4 · 词汇表】（默写版）：三列表格（Word / 词性 / 中文释义），**释义列留空**，供用户默写。

## 注意事项

- **风格纪律**：经济学人风格 ≠ 堆砌长句。长短句交替；数据、具体名词替代空泛形容词。
- **难度诚实**：除目标词外，尽量不引入考研大纲外生词；若有，给出中文注释。
- **忠实性**：中英内容一一对应，译文自然可读，不做逐字硬译。
- **词数不足**：用户给的词少于 100 个时，按实际数量执行，规则不变。
- 目标词若存在熟词僻义，释义取文章语境义；词汇表可同时标注常见义。
